# VPC Module
This module is devoloped for joinDevOps company. Projects inside joinDevOps follow this module to create their VPC.

## Inputs
* Project (required)         - Users should specify their project name
* environment (required)     - Users should specidy their enviroment
* cidr_block (optional)      - Users can provide their CIDR block. Default is 10.0.0.0/16
